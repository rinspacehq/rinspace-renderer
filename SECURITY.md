# Security reporting

Please report vulnerabilities through GitHub's **Security → Report a vulnerability** for
`rinspacehq/rinspace-renderer` when available. If private reporting is unavailable, email
`lunifans@outlook.com` with the affected version or digest, impact, and a minimal safe
reproduction. Do not put exploit details, credentials, or user data in a public issue or pull
request.

The maintained release line is identified by immutable release manifests. Candidate images and
unreviewed commits are not supported product versions. Maintainers will assess reports and
coordinate fixes and disclosure with the reporter; no response deadline or bounty is promised.
