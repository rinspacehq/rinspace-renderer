# Contributing to Rinspace Renderer

Use a focused pull request with synthetic fixtures and the relevant source checks from
[`README.md`](README.md). Discuss protocol, dependency, licensing, or security-boundary changes
before implementing them. Do not submit credentials, user works, private product code,
production logs, or third-party material without redistribution rights.

The repository's Rinspace-owned source is `AGPL-3.0-only`. Contributors must have the right to
submit their changes under that license and retain the copyright and notices of dependencies.
A pull request is a proposal, not a release or authorization to import it into Rinspace's
private product. The maintainer reviews the public change and separately decides whether an
immutable reviewed artifact should be tested and adopted by the product.

Report vulnerabilities privately as described in [`SECURITY.md`](SECURITY.md).
